## 环境准备

### 硬件要求

**最低配置**（可运行）：
- CPU：Intel i5 / AMD Ryzen 5（4 核）
- 内存：8GB RAM
- 存储：128GB SSD（至少 20GB 可用空间）
- 网络：稳定的互联网连接（用于 API 调用）

**推荐配置**（流畅运行）：
- CPU：Intel i7 / AMD Ryzen 7（8 核）
- 内存：16GB RAM
- 存储：256GB SSD（至少 50GB 可用空间）
- 网络：带宽 ≥10Mbps

### 软件要求

**操作系统**：
- Windows 11 / Windows 10（64 位）
- Ubuntu 22.04 LTS / 20.04 LTS
- macOS 12+

**必需软件**：
- Python 3.10 或 3.11（推荐 3.11）
- pip 23.0+
- Git（用于克隆项目）

**可选软件**：
- Ollama（如果使用本地 Light 层模型）
- VS Code / PyCharm（开发调试）

### 检查环境

```bash
# 检查 Python 版本
python --version  # 应显示 3.10.x 或 3.11.x

# 检查 pip 版本
pip --version

# 检查可用内存
free -h  # Linux
wmic OS get FreePhysicalMemory  # Windows

# 检查磁盘空间
df -h  # Linux
wmic logicaldisk get size,freespace,caption  # Windows
```

## 安装部署

### 方式一：快速部署（推荐）

```bash
# 1. 克隆项目
git clone https://github.com/your-org/agentic-rag-doc-generator.git
cd agentic-rag-doc-generator

# 2. 创建虚拟环境（推荐）
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入必要的 API Key

# 5. 初始化系统
python scripts/init_system.py

# 6. 启动服务
streamlit run ui/app.py
```

访问 http://localhost:8501 即可使用。

### 方式二：开发模式部署

```bash
# 1-4 步同上

# 5. 安装开发依赖
pip install -r requirements-dev.txt

# 6. 运行测试
pytest tests/

# 7. 启动服务（开发模式）
streamlit run ui/app.py --server.runOnSave true
```

### 验证安装

```bash
# 检查依赖是否正确安装
python -c "import chromadb; import docling; import langchain; print('OK')"

# 检查数据库是否初始化
ls -la data/chroma_db/  # 应该看到数据库文件

# 测试 LLM 连接
python scripts/test_llm_connection.py
```

## 配置说明

### 环境变量配置（.env）

```env
# ============================================
# LLM 配置
# ============================================

# High 层（规划/推理/审核）
LLM_HIGH_PROVIDER=anthropic
LLM_HIGH_MODEL=claude-opus-4-6
LLM_HIGH_TEMPERATURE=0.1
LLM_HIGH_MAX_TOKENS=4096

# Medium 层（内容撰写）
LLM_MEDIUM_PROVIDER=anthropic
LLM_MEDIUM_MODEL=claude-sonnet-4-6
LLM_MEDIUM_TEMPERATURE=0.3
LLM_MEDIUM_MAX_TOKENS=4096

# Light 层（检索优化）
LLM_LIGHT_PROVIDER=ollama
LLM_LIGHT_MODEL=qwen3.5:32b
LLM_LIGHT_TEMPERATURE=0.5
LLM_LIGHT_MAX_TOKENS=2048

# ============================================
# API Keys
# ============================================

ANTHROPIC_API_KEY=sk-ant-xxxxx
OPENAI_API_KEY=sk-xxxxx  # 可选

# ============================================
# 存储配置
# ============================================

CHROMA_PATH=./data/chroma_db
CHROMA_COLLECTION_NAME=documents

# ============================================
# 性能配置
# ============================================

# 文档摄入
BATCH_SIZE=20                    # 批处理大小（适配内存）
CHUNK_SIZE=512                   # 分块大小
CHUNK_OVERLAP=50                 # 分块重叠

# 检索配置
TOP_K=10                         # 检索返回数量
MAX_RETRIEVAL_ITERATIONS=5       # 最大检索迭代次数

# 并发配置
MAX_WORKERS=4                    # 最大并发数

# ============================================
# 日志配置
# ============================================

LOG_LEVEL=INFO                   # DEBUG/INFO/WARNING/ERROR
LOG_FILE=./logs/app.log
LOG_MAX_SIZE=10485760           # 10MB
LOG_BACKUP_COUNT=5

# ============================================
# 缓存配置
# ============================================

ENABLE_CACHE=true
CACHE_TTL=3600                  # 缓存过期时间（秒）
SEMANTIC_CACHE_THRESHOLD=0.95   # 语义缓存相似度阈值

# ============================================
# 监控配置
# ============================================

ENABLE_METRICS=true
METRICS_PORT=9090
```

### 配置模板说明

**LLM 配置组合方案**：

| 场景 | High | Medium | Light | 月成本（100 篇） |
|------|------|--------|-------|------------------|
| **最高质量** | Opus 4.6 | Sonnet 4.6 | Haiku | $50-70 |
| **平衡方案**（推荐） | Opus 4.6 | Sonnet 4.6 | Ollama 本地 | $30-50 |
| **最低成本** | Sonnet 4.6 | Haiku | Ollama 本地 | $15-25 |


## 启动与停止

### 启动服务

```bash
# 方式一：前台运行（开发/调试）
streamlit run ui/app.py

# 方式二：后台运行（生产）
nohup streamlit run ui/app.py > logs/streamlit.log 2>&1 &

# 方式三：使用 systemd（Linux 推荐）
sudo systemctl start agentic-rag
```

### 停止服务

```bash
# 方式一：前台运行时按 Ctrl+C

# 方式二：后台运行时
ps aux | grep streamlit
kill <PID>

# 方式三：systemd
sudo systemctl stop agentic-rag
```

### 重启服务

```bash
# 重启 Streamlit
sudo systemctl restart agentic-rag

# 或手动
kill <PID>
streamlit run ui/app.py
```

### 查看服务状态

```bash
# systemd 方式
sudo systemctl status agentic-rag

# 手动检查
ps aux | grep streamlit
netstat -tuln | grep 8501
```

### Systemd 配置（Linux）

创建 `/etc/systemd/system/agentic-rag.service`：

```ini
[Unit]
Description=Agentic RAG Document Generator
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/path/to/agentic-rag-doc-generator
Environment="PATH=/path/to/venv/bin"
ExecStart=/path/to/venv/bin/streamlit run ui/app.py
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable agentic-rag
sudo systemctl start agentic-rag
```

## 故障排查

### 常见问题

#### 1. 启动失败：端口被占用

**现象**：
```
OSError: [Errno 98] Address already in use
```

**解决**：
```bash
# 查找占用端口的进程
lsof -i :8501  # Linux/macOS
netstat -ano | findstr :8501  # Windows

# 杀死进程
kill <PID>  # Linux/macOS
taskkill /PID <PID> /F  # Windows

# 或更换端口
streamlit run ui/app.py --server.port 8502
```

#### 2. 内存不足

**现象**：
```
MemoryError: Unable to allocate array
```

**解决**：
```env
# 减小批处理大小
BATCH_SIZE=10  # 从 20 降到 10

# 减小分块大小
CHUNK_SIZE=256  # 从 512 降到 256

# 限制并发数
MAX_WORKERS=2  # 从 4 降到 2
```

#### 3. LLM API 调用失败

**现象**：
```
AuthenticationError: Invalid API key
```

**解决**：
```bash
# 检查 API Key 是否正确
echo $ANTHROPIC_API_KEY

# 测试 API 连接
python scripts/test_llm_connection.py

# 检查网络连接
curl https://api.anthropic.com/v1/messages
```

#### 4. Chroma 数据库损坏

**现象**：
```
sqlite3.DatabaseError: database disk image is malformed
```

**解决**：
```bash
# 备份现有数据库
cp -r data/chroma_db data/chroma_db.backup

# 重建数据库
rm -rf data/chroma_db
python scripts/init_system.py

# 重新上传文档
python scripts/upload_documents.py --dir ./data/documents
```

#### 5. 文档转换失败

**现象**：
```
DoclingError: Failed to convert document
```

**解决**：
```bash
# 检查文档格式是否支持
file document.pdf

# 尝试手动转换
python -c "from docling import DocumentConverter; \
           dc = DocumentConverter(); \
           result = dc.convert('document.pdf'); \
           print(result)"

# 如果仍失败，跳过该文档
python scripts/upload_documents.py --dir ./data/documents --skip-errors
```

#### 6. Ollama 模型无法加载

**现象**：
```
OllamaError: model not found
```

**解决**：
```bash
# 检查模型是否已下载
ollama list

# 重新拉取模型
ollama pull qwen3.5:32b

# 检查 Ollama 服务状态
systemctl status ollama  # Linux
```

## 备份恢复

### 备份策略

**每日备份**（推荐）：

```bash
#!/bin/bash
# backup.sh

DATE=$(date +%Y%m%d)
BACKUP_DIR="./backups/$DATE"

mkdir -p $BACKUP_DIR

# 备份数据库
cp -r data/chroma_db $BACKUP_DIR/

# 备份配置
cp .env $BACKUP_DIR/

# 备份日志
cp -r logs $BACKUP_DIR/

# 压缩
tar -czf $BACKUP_DIR.tar.gz $BACKUP_DIR
rm -rf $BACKUP_DIR

echo "Backup completed: $BACKUP_DIR.tar.gz"
```

设置定时任务（crontab）：

```bash
# 每天凌晨 2 点备份
0 2 * * * /path/to/backup.sh
```

### 恢复数据

```bash
# 1. 停止服务
sudo systemctl stop agentic-rag

# 2. 解压备份
tar -xzf backups/20260309.tar.gz

# 3. 恢复数据库
rm -rf data/chroma_db
cp -r backups/20260309/chroma_db data/

# 4. 恢复配置
cp backups/20260309/.env .env

# 5. 重启服务
sudo systemctl start agentic-rag
```

### 数据迁移

迁移到新服务器：

```bash
# 在旧服务器上
tar -czf agentic-rag-data.tar.gz data/ .env

# 传输到新服务器
scp agentic-rag-data.tar.gz user@new-server:/path/to/

# 在新服务器上
tar -xzf agentic-rag-data.tar.gz
python scripts/init_system.py
streamlit run ui/app.py
```

## 安全建议

### API Key 安全

- ✅ 使用 `.env` 文件存储，不要提交到 Git
- ✅ 定期轮换 API Key
- ✅ 限制 API Key 权限（如果平台支持）
- ❌ 不要在代码中硬编码 API Key

### 数据安全

- ✅ 定期备份数据库
- ✅ 限制文件访问权限（chmod 600 .env）
- ✅ 使用 HTTPS（如果对外暴露）
- ❌ 不要在公网直接暴露 Streamlit

### 网络安全

如果需要对外访问：

```bash
# 使用反向代理（Nginx）
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8501;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```
